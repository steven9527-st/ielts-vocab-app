## Context

当前 `pdf_parser.py` 正则将 `英[音标]` 作为非捕获分隔符处理。数据库 words 表只有 `english`、`chinese`、`status` 字段。前端所有页面仅展示英文和中文。

## Goals / Non-Goals

**Goals:**
- 解析 PDF 时提取英式音标（如 `[ə'bændən]`）和词性标记（如 `v.`、`adj.`）
- 音标和词性存入数据库并在各页面展示
- 向后兼容：已有数据新字段为空，不影响现有功能

**Non-Goals:**
- 不提取美式音标（当前 PDF 格式主要含英式音标）
- 不修改中文释义的解析逻辑
- 不做 TTS 发音功能

## Decisions

**正则改造**：将非捕获的 `英\s*\[.*?\]\s*` 改为捕获组 `(?:英\s*\[(.*?)\])?` 提取音标内容。词性从剩余内容中用 `_POS_STRIP_RE` 提取（已有逻辑），改为保留而非删除。

**数据库迁移**：使用 `ALTER TABLE ADD COLUMN` 而非重建表，避免丢失数据。

**前端布局**：
- 翻卡背面：单词上方加小字音标，词性跟在中文前或作为独立标签
- 词库列表：英文行下方以灰色小字显示 `[音标] pos.`

## Risks / Trade-offs

[不同 PDF 格式] → 当前正则已针对特定 IELTS PDF 格式设计，其他格式可能需要调整。保持宽松匹配策略。
[旧数据兼容] → ALTER TABLE 后旧记录的 phonetic/pos 为 NULL，代码中统一用空字符串兜底。
