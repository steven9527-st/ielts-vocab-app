# 翻卡可反复翻转

## Why

当前 `flashcard.html` 的翻卡逻辑使用 `flipped` 布尔标记锁死——用户首次点击/按 Space 翻到背面后，无法再翻回正面再看一遍单词。

实际学习场景下，用户经常需要：
1. 看到英文 → 翻面看释义 → 再翻回去验证自己有没有记住单词形态
2. 听到发音后再翻回去对照拼写

这种"反复横跳"的能力是翻卡学习的核心心智，缺失会被用户视为 bug。

## What Changes

- 翻卡支持**反复翻转**（每次点击/按 Space 都切换正反面）
- 首次翻到背面后，"下一张"按钮出现且**常驻**（不会因为翻回正面而消失）
- 提示文案随状态切换：正面显示"点击查看释义"，背面显示"点击返回正面"
- ArrowRight 快捷键的触发条件从"`flipped=true`"改为"曾经翻过"（`everFlipped=true`），保持原有"翻过才能去下一张"的约束
- 🔊 发音按钮的阻止冒泡逻辑保留不变
- 切换到下一张时，状态自然重置（页面重新渲染）

## Impact

- **Affected specs**：无（这是 UI 行为的细化，不引入新 capability）
  - 本 change 不创建 capability spec，仅作为 hotfix 性质的行为变更记录
- **Affected code**：
  - `templates/flashcard.html`：仅 `<script>` 块内的翻卡状态机重写
- **Breaking changes**：无（向后兼容，原有"翻一次→下一张"的工作流仍然有效）
- **Non-goals**：
  - 不改 CSS 翻转动画
  - 不改"放弃今日学习"逻辑
  - 不改后端任何路由或数据结构
